# python-hello

A simple first Python script to confirm my development setup and Git/GitHub workflow.

## How to run
1. Open the project folder in VS Code
2. Activate the virtual environment
   source .venv/bin/activate
3. Run the script
   python main.py

## What this demonstrates
- Python 3.14 environment setup
- Virtual environment usage
- Git commits and pushing to GitHub

## Notes
- The .venv folder is excluded via .gitignore
